-   React Native has no standard catalog and no CSS variables, so its `GenerativeUIProvider` has no `theme` prop: passing one is a type error, and a `theme` passed from JavaScript, or through a cast, is dropped, with a warning in development. Style the components of your own catalog with `StyleSheet`, as you style the rest of your app. See [Generative UI with your own components](/ag2/react-native#generative-ui-with-your-own-components).
